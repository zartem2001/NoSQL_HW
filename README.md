# Spring Boot + MongoDB — CRUD-приложение для управления пользователями

## 📋 Описание задачи

Создать Spring Boot-приложение, которое взаимодействует с базой данных **MongoDB** 
и выполняет CRUD-операции над коллекцией документов, представляющих сущности 
пользователей (`User`).

## 🎯 Цель

Отработать:
- Настройку подключения к **MongoDB** через Spring Data;
- Создание модели данных с аннотациями `@Document`, `@Id`;
- Реализацию репозитория через `MongoRepository`;
- Написание REST-контроллера с валидацией входных данных;
- Понимание разницы между реляционными и нереляционными (NoSQL) базами данных.

## 🛠️ Используемые технологии

- Java 17+
- Spring Boot (Spring Web, Spring Data MongoDB)
- MongoDB
- Maven / Gradle
